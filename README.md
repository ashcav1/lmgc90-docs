# LMGC90 for granular asteroid surfaces — documentation

Source of the book published at https://ashcav1.github.io/lmgc90-docs/ .
Built with mdBook by the GitHub Actions workflow on every push to `main`
(`.github/workflows/deploy.yml`); nothing needs to be installed locally.

LMGC90 itself is developed at LMGC (Montpellier): https://git-xen.lmgc.univ-montp2.fr/lmgc90/lmgc90_user .
This book is a practitioner's guide written while building a contact-dynamics
pipeline for a CubeSat landing on a boulder field (the Milani / Dimorphos
study); it documents the API as actually used, the solver's behaviour as
measured, and the failures encountered. It is not the official manual.
